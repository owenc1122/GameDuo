# PS2 模型实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 Blender 脚本生成 SCPH-30001 主机、DualShock 2、8 MB 记忆卡、美版 PS2 DVD 与光盘盒，导出带固定节点名的 USDZ 运行时资产。

**Architecture:** 一个共享辅助模块负责材质、圆角几何、节点命名和 USDZ 导出；每个物件一个建模脚本，从 `contract.json` 读取尺寸与节点约定。验证先写：Blender 内校验尺寸/面数/节点/运动极限相交，Swift 脚本在 SceneKit 中载入并驱动节点。

**Tech Stack:** Blender 5.2.2（M2，`/Applications/Blender.app/Contents/MacOS/Blender -b`）、Python bpy/bmesh、USD 导出、Swift + SceneKit（Xcode 27.0）。

**Spec:** `docs/superpowers/specs/2026-09-22-ps2-models-design.md`

---

## 文件结构

```
tools/ps2_blender/
  common.py              材质、圆角盒、倒角、节点父子、三角化、导出 USDZ
  contract.json          每个资产的目标尺寸、容差、节点、面数预算、运动范围
  validate_ps2.py        Blender 内验证：尺寸、面数、节点、运动极限相交
  verify_scenekit.swift  SceneKit 载入 USDZ、查找节点、执行动作
  run_all.sh             依次构建、验证、渲染
PS2_Disc_Case/
  source/build_dvd.py    光盘
  source/build_case.py   光盘盒（引用光盘）
  source/render.py
  REFERENCE_NOTES.md  README.md  validation.json  PS2_Disc_Case.blend  exports/  renders/
PS2_Model/
  source/build_memory_card.py
  source/build_console.py
  source/build_dualshock2.py
  source/render.py
  REFERENCE_NOTES.md  README.md  validation.json  PS2_Model.blend  exports/  renders/
DuoDS/Resources/PS2-*.usdz   导出副本（不改动 Xcode 工程，接入另做）
```

运行 Blender 脚本的统一命令（下文记作 `$B`）：

```bash
B="/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python-exit-code 1"
```

**Files:**

- Create: `tools/ps2_blender/contract.json`

- [ ] **Step 1：检索公开资料**：Sony SCPH-30001 官方规格（外形、重量）；iFixit PS2 拆机；公开高清正/背/侧视照片；DualShock 2 SCPH-10010 外形与按键布局；记忆卡 SCPH-10020 外形；美版 PS2 DVD 盒（Amaray 190×135×14 mm）与顶部横条比例；Printables/Thingiverse 上可下载的 PS2/DS2/记忆卡 CAD（只量尺寸，记录许可证）。
- [ ] **Step 2：写 REFERENCE_NOTES.md**：每个尺寸一行：值、来源 URL、等级（官方 / 交叉验证 / 照片校准）。
- [ ] **Step 3：写 contract.json**，结构固定如下（数值来自 Step 2）：

```json
{
  "tolerance_mm": 0.5,
  "assets": {
    "PS2-Console":    {"file": "PS2_Model/exports/PS2-Console.usdz", "root": "PS2_CONSOLE",
                        "size_mm": [301, 78, 182], "max_tris": 60000,
                        "nodes": ["DISC_TRAY","TRAY_DISC_ANCHOR","BTN_RESET","BTN_EJECT","LED_POWER","LED_EJECT",
                                  "PORT_CTRL_1","PORT_CTRL_2","SLOT_MC_1","SLOT_MC_2","TRADEMARK_PRINTS"],
                        "motions": [{"node":"DISC_TRAY","axis":"loc_z","range_m":[0, 0.0]},
                                    {"node":"BTN_RESET","axis":"loc_z","range_m":[0,-0.001]},
                                    {"node":"BTN_EJECT","axis":"loc_z","range_m":[0,-0.001]}]},
    "PS2-MemoryCard": {"file": "PS2_Model/exports/PS2-MemoryCard.usdz", "root": "PS2_MEMORY_CARD",
                        "size_mm": [0,0,0], "max_tris": 3000, "nodes": ["TRADEMARK_PRINTS"], "motions": []},
    "PS2-DualShock2": {"file": "PS2_Model/exports/PS2-DualShock2.usdz", "root": "DUALSHOCK2",
                        "size_mm": [0,0,0], "max_tris": 40000,
                        "nodes": ["DPAD","BTN_TRIANGLE","BTN_CIRCLE","BTN_CROSS","BTN_SQUARE","L1","R1","L2","R2",
                                  "STICK_L","STICK_R","BTN_SELECT","BTN_START","BTN_ANALOG","LED_ANALOG",
                                  "CABLE","CTRL_PLUG","TRADEMARK_PRINTS"],
                        "motions": []},
    "PS2-DVD":        {"file": "PS2_Disc_Case/exports/PS2-DVD.usdz", "root": "PS2_DVD",
                        "size_mm": [120, 1.2, 120], "max_tris": 4000, "nodes": ["DISC_LABEL"], "motions": []},
    "PS2-Case":       {"file": "PS2_Disc_Case/exports/PS2-Case.usdz", "root": "PS2_CASE",
                        "size_mm": [135, 190, 14], "max_tris": 11000,
                        "nodes": ["CASE_LID","CASE_DISC_ANCHOR","COVER_ART","TRADEMARK_PRINTS"],
                        "motions": [{"node":"CASE_LID","axis":"rot_y","range_rad":[0, 3.1416]}]}
  }
}
```

`size_mm` 为 [X 宽, Y 高, Z 深]，0 的项在 Step 2 查到后填入；托盘行程 `range_m[1]` 同样填实测值。填完后文件中不得留 0 占位。

- [ ] **Step 4：Commit** `git add tools/ps2_blender/contract.json PS2_*/REFERENCE_NOTES.md && git commit -m "ps2: reference notes and asset contract"`

### Task 2：验证脚本（先写，预期失败）

**Files:**
- Create: `tools/ps2_blender/validate_ps2.py`、`tools/ps2_blender/verify_scenekit.swift`

- [ ] **Step 1：validate_ps2.py**。对 contract 中每个资产：导入 USDZ 到空场景；按根节点求世界包围盒并与 `size_mm` 比较（容差 0.5 mm）；统计三角面；检查节点名存在（USD 导入可能给同名 transform 加 geometry 子节点，按名称前缀匹配）；对每个 motion 把节点分别设到两端，用 `mathutils.bvhtree.BVHTree` 检查该节点子树与其余网格无相交；把结果写入各目录的 `validation.json`，任一失败则 `sys.exit(1)`。
- [ ] **Step 2：verify_scenekit.swift**。`SCNScene(url:)` 载入每个 USDZ；`childNode(withName:recursively:)` 找全部节点；对 motion 节点设置极限值；打印 `OK <asset>` 或 `FAIL <asset>: <原因>`，有失败时 `exit(1)`。
- [ ] **Step 3：运行，确认失败**：`$B --python tools/ps2_blender/validate_ps2.py`，预期所有资产报 “file not found” 并退出码 1。
- [ ] **Step 4：Commit**。
