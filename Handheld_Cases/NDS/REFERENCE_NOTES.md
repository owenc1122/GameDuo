# 美版 Nintendo DS 游戏盒：参考数据

本文件只记录数据与来源。数值与 `source/build_nds_case.py` 的常量及其生成的 `contract.json` 一致，单位 mm。

等级：
- **多源**：两个以上独立来源一致或相近。
- **实测**：直接从仓库里的文件量得（App 卡带模型、GameTDB 扫描图尺寸）。
- **照片校准**：以外形尺寸为比例尺在照片上量得，注明像素。
- **估计**：照片看不清，按结构推断。

坐标：盒子关闭、竖放，正面 +Z，书脊 −X，根节点在包围盒底面中心，x −67.5…67.5，y 0…122，z −7.25…7.25。照片坐标写成“距铰链边 / 距顶边”（盒子打开、内面朝上时的托盘或盒盖），换算为 X = −67.5 + 距铰链边（托盘），Y = 122 − 距顶边。

## 3. App 卡带模型（实测）

`DuoDS/Resources/Detailed-Cartridges.usdz`，prim `/root/ndsStandard`，stage upAxis Z、metersPerUnit 1.0，但数值是毫米；`/root` 与 `ndsStandard` 都没有变换。用 pxr BBoxCache 与 Blender USD 导入两种方式测量，结果相同：

| 部件 | X | Y | Z |
|---|---|---|---|
| 整体包围盒 | −16.5 … 16.501 | −17.5 … 17.5 | −3.915 … 0.043 |
| Front_cover（正面壳） | ±16.5 | ±17.5 | −1.86 … 0.0 |
| Back_cover（背面壳） | ±16.5 | ±17.5 | −3.8 … −1.95 |
| Label_recess_bed（标签凹槽，朝 +Z） | ±13.45 | −10.45 … 12.65 | −0.25 … −0.15 |
| Gold_contact_*（金手指，背面） | −9 … 12 | y ≈ −12 | ≈ −3.17 |
| Front_platform（标签上方小平台） | ±3.8 | 14.48 … 15.30 | … 0.043 |
| 背面模压字（最低点） | | | −3.915 |

结论：卡带本地 +Z = 标签面法线，+Y = 上，金手指在 −Y；机身中心在本地 (0, 0, −1.9)。锚点放在机身中心，卡带挂到锚点下时 position = (0, 0, +1.9 mm)、scale 0.001、旋转单位。脚本每次构建都重新测量并与常量比对。
